# Lithica Suite

Lithica Suite es un ecosistema de aplicaciones para trabajo de campo, cartografía, conocimiento geocientífico, geotecnia, modelamiento y educación.

## Proyectos

| Proyecto | Función principal | Estado al 1 de agosto de 2026 |
| --- | --- | --- |
| Lithica Explorer | Captura, consulta y gestión de información geológica de campo | Desarrollo avanzado; Android 1.4.0+25 con AAB disponible |
| Lithica Mapper | Creación y edición de cartografía geológica | Desarrollo avanzado; Android 0.3.0+6 |
| Lithica Atlas | Consulta bilingüe de conocimiento geocientífico | Desarrollo avanzado; pendiente cerrar versión y contenido público |
| Lithica GeoTech | Consulta y cálculos geotécnicos | Desarrollo avanzado para Android y Windows; pendiente regularizar versión |
| Lithica GeoModeller | Modelamiento geológico implícito | Proyecto conceptual; directorio sin implementación |
| Lithica Academy | Formación integrada con las aplicaciones Lithica | Proyecto conceptual; directorio sin implementación |

Las fichas de apps distinguen lo implementado, lo pendiente y la visión futura de cada producto. La existencia de código o configuración no equivale por sí sola a validación completa en dispositivo o publicación.

## Flujo del ecosistema

1. Explorer registra observaciones y evidencia de campo.
2. Mapper organiza, edita y presenta la información espacial.
3. GeoModeller transformará evidencia e interpretación en modelos geológicos.
4. Atlas conserva y consulta conocimiento geocientífico con fuentes y atribuciones.
5. GeoTech aporta clasificación geomecánica y cálculos de ingeniería.
6. Academy conectará herramientas y contenidos mediante actividades educativas.
