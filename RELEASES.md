## Android y QGIS

| Producto | Disponibilidad | Enlace |
| --- | --- | --- |
| Explorer | Google Play para Android | [Abrir Google Play](https://play.google.com/store/apps/details?id=com.gisgeodev.lithicaexplorer) |
| Mapper | Google Play para Android | [Abrir Google Play](https://play.google.com/store/apps/details?id=com.gisgeodev.lithicamapper) |
| Atlas | Google Play para Android | [Abrir Google Play](https://play.google.com/store/apps/details?id=com.gisgeodev.lithica.atlas) |
| GeoTech | Prueba cerrada; requiere acceso habilitado | [Solicitar acceso](https://forms.gle/GtNmVjVvpPzs2q5u6) |
| Cloud Sync | Plugin para QGIS 3.34 o posterior | [Descargar ZIP 2.0.4](https://github.com/jordan-zav/Lithica-Cloud-Sync/releases/download/v2.0.4/Lithica.Cloud.Sync-2.0.4.zip) · [Releases](https://github.com/jordan-zav/Lithica-Cloud-Sync/releases) |

Para instalar Cloud Sync desde el ZIP, abre QGIS y entra en Complementos → Administrar e instalar complementos → Instalar a partir de un archivo ZIP. Consulta [su ficha](apps/LITHICA_CLOUD_SYNC.md) y las [instrucciones del plugin](https://github.com/jordan-zav/Lithica-Cloud-Sync#readme).
