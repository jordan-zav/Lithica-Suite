# Lithica Spectra

Estado revisado el 4 de octubre de 2026 a partir del repositorio del producto.

Spectra es la aplicación de teledetección y análisis espectral de Lithica Suite. Tiene una interfaz Flutter de escritorio y un motor Python para administrar proyectos, áreas de estudio, imágenes multibanda y procesamiento raster local.

El proyecto incorpora proveedores Earth Engine y OpenTopography, operaciones de bandas, visualización RGB, herramientas de terreno y clasificación Spectral Angle Mapper. El acceso a los proveedores depende de las credenciales y autorizaciones propias de cada usuario.

La existencia de código y flujos de desarrollo no confirma una publicación comercial o un instalador público. Las decisiones de licenciamiento y estrategia se mantienen en la documentación interna de Lithica Secrets.
