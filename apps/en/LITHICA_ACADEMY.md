# Lithica Academy

**Learn through data and practice.** Spanish-language geoscience learning paths with exercises, reference sources and quality-control checkpoints.

## What you can do

- Leapfrog Geo fundamentals: drillholes, GIS, topography and geological models.
- Oasis montaj with Mt Palmer: preparation, processing and interpretation.
- Oasis montaj GravMag: gridding, filters and Euler 3D.
- Prerequisites, exercises and sources organized by module and edition.

## Use and availability

This is educational material, not an Android app. Lessons retain each module's reference edition and software version. Use public, synthetic or authorized data; named software retains its own terms and trademarks.

**Status:** Educational content.
