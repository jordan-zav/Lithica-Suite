# Lithica Notebook

**Read, annotate, study and compute.** Combine scientific reading, PDF annotations, a working library, study planning and optional notebook execution on your own device.

## What you can do

- IPYNB, PDF, HTML, Markdown, Office documents, EPUB, tables and images.
- Annotations and working copies stored separately from originals.
- A planner, timer and local reminders subject to system permissions.
- Lithica Lab: local Python on Android and Windows, with dependency preparation.

## Use and availability

Opening a document does not run its code. Lab runs only when requested and may need connectivity to install compatible packages. It cannot run every desktop package or guarantee identical Word layouts in exports. No verified public download is offered yet.

**Status:** In development.
