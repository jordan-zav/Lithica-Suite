# Downloads and access

Choose each product's official channel. Applications and components are distributed separately.

## Android and QGIS

| Product | Availability | Link |
| --- | --- | --- |
| Explorer | Google Play for Android | [Open Google Play](https://play.google.com/store/apps/details?id=com.gisgeodev.lithicaexplorer) |
| Mapper | Google Play for Android | [Open Google Play](https://play.google.com/store/apps/details?id=com.gisgeodev.lithicamapper) |
| Atlas | Google Play for Android | [Open Google Play](https://play.google.com/store/apps/details?id=com.gisgeodev.lithica.atlas) |
| GeoTech | Closed testing; an eligible account is required | [Request access](https://forms.gle/GtNmVjVvpPzs2q5u6) |
| Cloud Sync | QGIS 3.34 or later | [Download ZIP 2.0.4](https://github.com/jordan-zav/Lithica-Cloud-Sync/releases/download/v2.0.4/Lithica.Cloud.Sync-2.0.4.zip) · [Releases](https://github.com/jordan-zav/Lithica-Cloud-Sync/releases) |

To install Cloud Sync from a ZIP, open QGIS and choose Plugins → Manage and Install Plugins → Install from ZIP. See its [product page](apps/en/LITHICA_CLOUD_SYNC.md) and [plugin instructions](https://github.com/jordan-zav/Lithica-Cloud-Sync#readme).
